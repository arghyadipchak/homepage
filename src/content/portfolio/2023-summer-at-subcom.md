## Highlights

- Integrated native Rust into an Android persistent foreground service via JNI/NDK, performing real-time filesystem monitoring and local telemetry ([android_rust_service](https://github.com/SubconsciousCompute/android_rust_service/))
- Implemented a [Secret Handshake protocol](https://subcom.notion.site/Secret-Handshake-over-Untrusted-Network-b48a0165eb594c2daa9007943ddf82e2), establishing encrypted P2P channels with mutual authentication and forward secrecy over untrusted networks
- Ported Windows Native API bindings ([ntapi](https://github.com/MSxDOS/ntapi/pull/17)) from `winapi` to `windows-sys`, updating NT kernel struct definitions, layout tests, and `ntdll` linking
